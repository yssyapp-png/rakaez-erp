# Rakaez Parts Platform

منصة ركائز لإدارة محلات قطع غيار السيارات والمخزون وطلبات الورش.

هذا المصدر مخصص حصريًا لمشروع **ركائز لقطع غيار السيارات**. راجع `docs/PROJECT-SCOPE.md` لمعرفة حدود المشروع والمستودعات المعتمدة.

## التشغيل على macOS وVS Code

1. ثبّت Node.js 22 LTS وGit وVS Code.
2. افتح Terminal داخل مجلد المشروع ونفّذ `npm ci`.
3. نفّذ `npm run lint && npm test` قبل أي تعديل أو رفع.
4. شغّل بيئة التطوير بالأمر `npm run dev` ثم افتح العنوان الذي يظهر في الطرفية.

الأوامر المتاحة:

- `npm run dev`: تشغيل بيئة التطوير.
- `npm run build`: إنشاء نسخة الإنتاج.
- `npm run start`: تشغيل نسخة الإنتاج المبنية.
- `npm test`: بناء المشروع وتنفيذ اختبارات التحقق.
- `npm run db:generate`: إنشاء ترحيلات قاعدة البيانات بعد تعديل المخطط.

## الرفع إلى GitHub

أنشئ مستودعًا خاصًا فارغًا، ثم من داخل مجلد المشروع:

```bash
git init
git add .
git commit -m "Initial Rakaez release candidate"
git branch -M main
git remote add origin https://github.com/USERNAME/rakaez-parts.git
git push -u origin main
```

استبدل `USERNAME` باسم حسابك. لا تضع مفاتيح أو كلمات مرور في المشروع. فحص GitHub الموجود في `.github/workflows/ci.yml` يشغّل التدقيق والبناء والاختبارات تلقائيًا مع كل تحديث.

## المكونات الرئيسية

- واجهة عربية أساسية مع دعم الإنجليزية.
- إدارة المخزون وأرقام القطع القياسية.
- متابعة طلبات الورش وحالة التجهيز.
- قاعدة بيانات D1 مع مخطط وترحيلات منظمة.
- إعدادات نشر منفصلة عن واجهة المستخدم.

## متطلبات التشغيل

- VS Code (اختياري)
