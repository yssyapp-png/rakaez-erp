# سياسة الأمان

لا تنشر تفاصيل الثغرات في البلاغات العامة. أرسل البلاغ إلى قناة أمنية خاصة يحددها مالك المشروع، مع وصف الأثر وخطوات إعادة المشكلة، من دون تضمين بيانات عملاء حقيقية.

## ضوابط المساهمة

- يمنع حفظ كلمات المرور أو الرموز أو ملفات البيئة داخل Git.
- يلزم اجتياز `npm run lint` و`npm test` وفحص تبعيات التشغيل قبل الدمج.
- يمنع استخدام بيانات إنتاج حقيقية في التطوير أو الاختبارات.
- تُراجع صلاحيات الموظفين وسجلات التدقيق وفق مبدأ أقل صلاحية.

هذا الملف إجراء تشغيلي للمشروع، ولا يمثل شهادة امتثال أو اعتمادًا من جهة حكومية.
