# نطاق مشروع ركائز لقطع غيار السيارات

هذا المستودع مخصص حصريًا لمنصة **ركائز لقطع غيار السيارات — Rakaez Auto Parts**.

يشمل النطاق:

- كتالوج السيارات وأرقام القطع الإنجليزية وبيانات OEM والبدائل والتوافق.
- المحلات والفروع والورش والمخزون والأسعار والمبيعات والفواتير والاشتراكات.
- البحث المتدرج حسب السيارة، والتوسع اللاحق في VIN والتكاملات المرخصة.
- الواجهة العربية والإنجليزية وإدارة الصلاحيات وعزل بيانات كل منشأة.

لا يشمل هذا المستودع مشروع Coffee أو تطبيقات القرآن الكريم والأذكار أو أي مشروع آخر.

## المستودعات المعتمدة

- الويب ونظام ERP: `rakaez-erp`
- تطبيق الجوال: `rakaez-parts-mobile`

يبقى كود الويب منفصلًا عن كود تطبيق الجوال، ويشتركان فقط في العقود البرمجية الموثقة وواجهات API الآمنة.
