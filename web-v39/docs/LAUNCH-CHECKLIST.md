## مطلوبة قبل الاختبار ببيانات شبه حقيقية

- [ ] إضافة تسجيل دخول ومصادقة متعددة العوامل وأدوار وصلاحيات.
- [ ] اختبار عزل بيانات كل متجر ومستودع وورشة آليًا.
- [ ] استخدام بيانات تجريبية مجهولة فقط وخطة نسخ احتياطي واستعادة مجرّبة.
- [ ] إضافة سجل تدقيق غير قابل للتعديل للعمليات الحساسة.

## مطلوبة قبل الإطلاق التجاري العام

- [ ] مراجعة مستقلة لاختبار الاختراق ومعالجة النتائج.
- [ ] مراجعة التوافق مع نظام حماية البيانات الشخصية السعودي وضوابط NCA المناسبة لنطاق المنشأة.
- [ ] تفعيل DNSSEC وقفل نقل النطاق والمصادقة الثنائية والتنبيهات لدى مسجل النطاق.
- [ ] تفعيل مراقبة الأعطال والسجلات والتنبيهات وخطة استجابة للحوادث على مدار الساعة.
- [ ] اختبار الاستعادة من النسخ الاحتياطية والتعافي من الكوارث وموقع تشغيل احتياطي.
- [ ] دمج بوابة دفع مرخصة واختبار التسوية والاسترجاع؛ لا تُخزّن بيانات البطاقة في المنصة.
- [ ] تنفيذ مزامنة العمل دون إنترنت وحل التعارضات واختبار خصم المخزون والدفع المؤجل ميدانيًا.
- [ ] مراجعة دقة المحتوى العربي والإنجليزي وأرقام القطع الإنجليزية واعتماد بيانات الكتالوج وترخيصها.
- [ ] اختبار الحمل والسعة وفق عدد المتاجر والمستخدمين والمعاملات المتوقع فعليًا.

لا يجوز وصف النظام بأنه معتمد من جهة أمن سيبراني سعودية إلا بعد الحصول على اعتماد رسمي موثق.
